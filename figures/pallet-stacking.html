Column vs interlock stacking

How you arrange boxes on each layer is a trade-off. Column stacking puts every box straight on top of the one below — corners line up, so it carries weight best, but the layers aren't tied together and it leans easily. Interlock turns alternate layers 90° so boxes bridge the seams below — much steadier, but each box bears less because the load spreads off its corners.
